JARINGAN PERANGKAT

Profil WiFi ESP32

Tambahkan hingga 5 jaringan 2,4 GHz. Perangkat mencoba jaringan secara bergiliran.

Tetap terhubung

Sertakan jaringan yang sudah bekerja sebagai cadangan. Saat profil dikirim, koneksi ESP32 dapat terputus sementara.

Simpan satu profil hotspot HP untuk pemulihan. Bluetooth yang mati memerlukan koneksi WiFi dan Firebase agar dapat diaktifkan kembali.

Password hanya dikirim saat Anda menyimpan profil. Form dikosongkan setelah diterima ESP32. Profil tersimpan di perangkat; firmware belum menyediakan pembacaan kembali daftar profil.

Profil awal di secrets.h tetap menjadi cadangan jika SSID-nya tidak ditimpa oleh profil baru.
